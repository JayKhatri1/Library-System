# Digital Library Management System

A full-stack Library Management System built using
React, Node.js, Express and MongoDB.

## Features

### User
- Register and login
- View books
- Search books
- Borrow books
- Return books
- View transactions
- Automatic overdue fine calculation

### Admin
- Admin authentication
- Dashboard
- Manage users
- Manage books
- Manage categories
- View transactions
- View overdue books

## Technology Stack

Frontend:
- React
- Vite
- Axios
- React Router

Backend:
- Node.js
- Express.js
- JWT
- bcrypt

Database:
- MongoDB Atlas

Deployment:
- Vercel
- Render

## Security

- Password hashing using bcrypt
- JWT authentication
- Role-based authorization
- Protected admin APIs
- CORS protection
- Environment variables
- Rate limiting
